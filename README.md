# claude-skills

Personal [Claude Code skills](https://docs.claude.com/en/docs/claude-code/skills) I've built for my own workflow.

## Skills

- **checkout-branch**: orient on the current git branch (log, status, diff, open PR) before starting work
- **checkout-repo**: build background on a whole repo (docs, stack, structure) before starting work
- **manage-workspaces**: reference for my VS Code `.code-workspace` files
- **skill-audit**: survey Claude Code skills across config, disk, and actual usage, and clean up the dead ones
- **tokensave-cleanup**: survey and clean up stale [tokensave](https://github.com/aovestdipaperino/tokensave) code-graph indexes
- **update-tools**: check for and apply updates to machine-wide dev tools
